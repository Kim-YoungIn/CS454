# Labelled next-session generalization bank (v2)

**Data only: no adversarial attacks have been run on this bank.** There are ten development and ten confirmation photographs, one per Imagenette class/role. Each selected input has a VGG-11 clean argmax equal to the official ImageNet1000 label. This is an eligibility condition matching the assignment's initially correct seeds, not a classifier accuracy result.

The [official Imagenette archive](https://github.com/fastai/imagenette#the-datasets), its verified MD5/SHA256, exact synset/class-index mapping and primary provenance are documented in `../generalization_next_bank.md`. All inputs originate from official Imagenette `val`; this is an ImageNet-derived resplit and does not establish exclusion from VGG pretraining. Source images have a 160px short side. Preparation converts decoded images to RGB PNG without resizing; the unchanged instructor utility supplies its usual 224px preprocessing.

`protocol.json` fixes the class/role pools before clean forwards: SHA256(seed+NUL+archive member) ordering, even/odd development/confirmation partitions, at most ten candidates per class/role, first clean-correct input, no confidence threshold or attack-result filtering. Exact byte duplicates are excluded deterministically. `pools_before_clean.csv`, `pools.csv`, `eligibility.csv` and `unfilled.json` retain every pool choice, scanned exclusion and missing class. Twenty images were selected from 28 scanned records; eight had a clean-label mismatch, and no role/class remained unfilled. No exact selected original-byte duplicates exist. Coverage remains limited to ten classes.

`manifest.csv` pins selected labels, prepared/original hashes and archive paths; `environment.json` pins the classifier/preprocessing sources, checkpoint hash and package versions. `selector_snapshot.py` is the exact selector used. `originals/` also retains the fixed candidate pool, including unscanned candidates; these are not extra selected evaluation cases. Only the twenty manifest rows form this bank.
