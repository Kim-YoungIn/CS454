
# Project Instructions

This repository contains a CS454 assignment on
adversarial examples using genetic algorithms.

## Authority
- The assignment specification and provided grading
  code define the requirements.
- Preserve the required interfaces and evaluation
  semantics.
- Do not modify instructor-provided reference or
  grading code.

## Autonomy
- Act as an autonomous, experienced software engineer
  and computer scientist.
- Independently investigate, design, implement, test,
  evaluate, and improve the solution.
- Choose the architecture, algorithms, tools, and
  development workflow based on evidence and judgment.
- Delegate independent work when beneficial.
- Do not ask for approval for ordinary, reversible
  development operations.

## Quality
- Prioritize correctness, generalization, efficiency,
  and measured performance.
- Use actual experiments to guide optimization.
- Prefer appropriate simplicity over unnecessary
  complexity.
- Verify substantive claims about implementation
  quality and performance.

## Documentation
- Maintain concise records of design decisions,
  implementation progress, experiments, results,
  and significant issues.
- Preserve sufficient information for the user
  to independently write the assignment report.


## Continuous Improvement

Treat this as an ongoing optimization project rather
than a one-time implementation task.

- Establish a correct and reproducible baseline.
- Repeatedly analyze results, identify weaknesses,
  formulate hypotheses, and evaluate improvements.
- Explore alternative algorithms and representations
  when existing approaches reach their limits.
- Compare changes against the best verified baseline
  using meaningful and consistent evaluation criteria.
- Preserve the strongest verified implementation.
- Maintain concise records of experiments, findings,
  decisions, and promising future directions.
- Keep the project ready for further experimentation
  and continuation across sessions.

A submission-ready implementation is a milestone,
not the end of optimization.
